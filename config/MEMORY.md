## 安全规则（2026-03-01 从 OpenClaw 迁移）

### 权限分级

| 级别 | 权限 | 审批要求 | 适用场景 |
|------|------|----------|----------|
| **L0** | 公开查询 | 无需 | 天气、新闻、常识问题 |
| **L1** | 常规操作 | 无需 | 技能使用、文档读写 |
| **L2** | 敏感操作 | 需要审批 | 文件读取、命令执行 |
| **L3** | 系统操作 | 仅@陈志强授权 | 配置文件修改、系统命令 |

### 敏感操作黑名单

> 群聊中**不执行**，需私聊审批：

| 操作类型 | 示例 |
|----------|------|
| 配置文件 | 读取 openclaw.json、providers.json |
| API密钥 | 发送任何含 Key 的内容 |
| 系统命令 | 重启/修改系统配置 |
| 敏感路径 | C:/windows/、C:/Users/... |
| 加密密钥 | 发送加密前的密钥 |

### 飞书群特殊限制

> 当 channel 包含 "feishu" 时自动生效：

1. ❌ 禁止读取或提及任何个人隐私信息
2. ❌ 禁止访问用户的私人文件、历史记录
3. ❌ 只能回答公开的、常识性的问题
4. ❌ 禁止调用任何需要认证的工具访问私人数据
5. ✅ 如遇隐私问题，回复："抱歉，我无法提供此类信息"

### 审批流程

```
收到请求 → 检查权限级别 → 需要审批？
    ├── 否 → 执行
    └── 是 → 提示私聊确认 → 审批通过 → 执行 → 记录日志
```

## 历史经验

### 2026-03-01

- Copaw + Ollama 401 错误已修复
- 原因：api_key 为空导致空的 Authorization header
- 解决：设置任意 api_key 值（如 "ollama"）
- 配置位置：`~/.copaw/venv/Lib/site-packages/copaw/providers/providers.json`

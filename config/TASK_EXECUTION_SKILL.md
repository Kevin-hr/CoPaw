SKILL: 诚信友善型任务执行流程

1. 任务分解
   - 采用透明化分工，确保每个环节责任人明确
   - 使用协作工具（如Notion/飞书）同步进度
   - 建立诚信检查点：每日15:00同步进展

2. 执行保障
   - 诚信工具包：
     ▫️ 透明日志模板（含时间戳+操作记录）
     ▫️ 问题反馈通道（匿名/实名双选项）
   - 友善执行准则：
     ▫️ 每日早会5分钟正向反馈
     ▫️ 异常处理遵循"三明治沟通法"

3. 质量验证
   - 三重检查机制：
     1. 自我复核（诚信度自检表）
     2. 同事交叉验证（友善度评分卡）
     3. 领导终审（含3个维度评分）

4. 效果反馈
   - 建立双向反馈机制：
     ▫️ 任务完成度雷达图
     ▫️ 诚信友善指数仪表盘
   - 持续改进：
     每月1次复盘会（采用5Why分析法）

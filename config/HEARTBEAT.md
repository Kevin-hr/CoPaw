# HEARTBEAT.md - 定期检查任务配置

## 检查频率说明
- 配置文件被读取时执行所有任务
- 建议每30-60分钟检查一次
- 避免过于频繁的检查，减少API消耗

## 定期任务列表

### 1. 检查电子邮件（每日3次）
**时间:** 09:00, 14:00, 20:00
**任务:** 使用 himalaya 技能检查收件箱，标记重要邮件

### 2. 查看日历事件（每日2次）
**时间:** 08:00, 17:00
**任务:** 检查今天和明天的日程安排，提前提醒即将到来的事件

### 3. 系统状态检查（每2小时）
**任务:** 
- 检查磁盘使用情况
- 检查网络连接状态
- 验证关键服务运行状态

### 4. 项目进度监控（工作日10:00, 16:00）
**任务:** 
- 检查指定目录的项目文件是否有更新
- 提醒截止日期临近的任务

### 5. 新闻摘要（早上8:30）
**时间:** 08:30
**任务:** 使用 news 技能获取头条新闻摘要
